Day-ahead electricity demand forecast for Colombia

Every day a model forecasts the hourly demand of the national grid for the next day and writes it to a public log before that day starts. Once the grid operator (XM) publishes the actual demand, about six days later, each forecast is scored here.

How to read this page

The forecast log only grows: a scheduled job appends 24 lines a day and never rewrites one, so the history of the repository shows that each forecast existed before its day. A day without a run stays empty; nothing is filled in afterwards.

The backtest figure is the error of the same model over the previous twelve months, replayed with only the data that was published at each moment. The live error is expected to sit near it; an issue is opened automatically when the last seven evaluated days exceed 1.5 times that figure.
